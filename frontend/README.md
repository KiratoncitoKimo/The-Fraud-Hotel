
# The Fraud Hotel — Frontend

Frontend aplikacji do zarządzania hotelem.

## Technologie

- React
- TypeScript
- Vite
- React Router

## Wymagania

- Node.js
- npm

## Instalacja

Przejdź do katalogu `frontend`:

```bash
cd frontend
npm install
```

## Uruchomienie

```bash
npm run dev
```

Aplikacja będzie dostępna pod adresem wyświetlonym w terminalu, zazwyczaj http://localhost:5173/.

## Struktura projektu

- `src/components/` — komponenty wielokrotnego użytku
- `src/pages/` — widoki użytkownika i administratora
- `src/App.tsx` — konfiguracja nawigacji

## Backend

Frontend jest rozwijany niezależnie od istniejącego backendu Flask. Integracja z API zostanie dodana w kolejnych etapach.
